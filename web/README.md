# 🖥️ AirClass 관리자 웹

학교 행정실에서 **전체 교실(24곳)의 공기질과 장치를 한 화면에서 관리**하는 웹이에요.
교실 상태를 보고, 공기청정기·창문을 원격으로 제어하고, 발생한 알림을 처리 상태까지 관리해요.

> 지금은 `shared/dummyData.js`의 더미 데이터로 동작해요. 데이터는 모두 `src/api.js`를 거치므로, 백엔드를 붙일 때 이 파일만 바꾸면 돼요.

---

## 화면

### 📊 대시보드 `/`
- **요약 카드**: 관리 교실 수(정상 · 주의 · 경고), 실외 PM2.5, 평균 실내 PM2.5, 평균 CO₂, 공기청정기 가동 수
- **교실 상태 맵**: 층별로 교실을 색(🟢 정상 · 🟠 주의 · 🔴 경고)으로 표시. 교실을 누르면 오른쪽에 상세 패널
- **교실 상세 패널**: 수치, 공기청정기 전원 · 자동 제어, 창문 열기 · 닫기, 적용된 규칙
- **오늘 실내·실외 PM2.5 추이**: 24시간 그래프(3시간 간격, 마지막 점은 현재값)
- **실시간 알림** 목록

### 🔍 교실별 모니터링 `/monitoring`
- 지금 확인이 필요한 교실 카드
- 전체 교실 표: 상태 · PM2.5 · CO₂ · 온도 · 습도, **층·상태 필터와 열 정렬**
- 교실을 누르면 **교실 상세** `/monitoring/:id` → 24시간 CO₂·PM2.5 추이, 장치 제어 이력

### 🎛️ 장치 제어 `/devices`
- **일괄 제어** 3단계(대상 → 동작 → 확인): 전원 켜기 · 끄기, 자동 모드로, 풍량 강으로, **창문 모두 닫기**
- **교실 장치 목록**: 공기청정기 모드 · 풍량 · 전원, 창문 상태 · 열기/닫기 · 추천 표시
- **자동 제어 규칙** 켜기/끄기, **최근 제어 기록**

### 🔔 알림 이력 `/alerts`
- 목록 + 선택한 알림의 처리 타임라인
- 상태 구분: 자동 처리 · 대응 완료 · 미확인 / 기간: 오늘 · 최근 7일
- **재전송**, **처리 완료** 표시, **CSV 내보내기**

### ⚙️ 설정 `/settings`
| 메뉴 | 내용 |
|---|---|
| 기준값 | PM2.5 · CO₂ 판단 기준 (바꾸면 영향받는 교실 수 미리보기) |
| 알림 | 알림 종류, 반복 간격(15분 · 30분 · 1시간) |
| 교실·담임 | 교실별 담임 선생님 지정 |
| 실외 데이터 | 학교 센서 / 공공 API 우선순위 |
| 계정 | 비밀번호 변경, 로그아웃 |

### 🔐 계정 `/login` · `/signup` · `/find`
- 로그인(로그인 상태 유지 선택), 3단계 회원가입, 아이디/비밀번호 찾기
- 비밀번호 5번 틀리면 1분 잠금
- 로그인하지 않으면 모든 화면이 로그인 페이지로 이동하고, 로그인 후 원래 가려던 화면으로 돌아가요.

## 판단 기준 (`shared/rules.js`, 앱과 공용)

| 조건 | 판정 / 동작 |
|---|---|
| 실내 PM2.5 ≥ 35 | 🔴 경고 · 공기청정기 자동 ON |
| CO₂ ≥ 1,000 + 실외 양호 | 🟠 주의 · 창문 **열기 추천** |
| CO₂ ≥ 1,000 + 실외 나쁨(≥ 36) 또는 알 수 없음 | 🟠 주의 · 창문 **닫기 추천** + 공기청정기 가동 |
| 모두 정상 | 🟢 정상 · 절전 대기 |

실외값은 학교 센서를 우선 쓰고, 센서 이상 · 습도 80% 이상이면 공공 API 값으로 대신해요.
창문은 자동으로 움직이지 않아요. 추천만 하고 사람이 버튼을 눌러야 실행돼요.

## 실행

```bash
npm install
npm run dev       # 개발 서버 http://localhost:5173
npm run build     # 배포용 빌드 → dist/
npm run lint      # oxlint 검사
npm test          # 시나리오별 자동 제어 결과 확인
```

라즈베리파이에서는 루트의 `docker compose up -d --build`가 빌드해서 nginx로 `/`에 띄워요.

## 구조

```
src/
├── App.jsx        # 라우트 (계정 페이지는 공개, 나머지는 로그인 필요)
├── Layout.jsx     # 사이드바 · 상단바 · 로그아웃, 시나리오·장치 상태를 모든 화면이 공유
├── api.js         # 데이터 접근 창구 (지금: shared/ 더미 → 나중: 백엔드 API)
├── api.test.js    # 규칙 동작 테스트
├── auth/          # AuthContext(로그인 상태), Login · Signup · Find, authApi(데모용 인증)
├── pages/         # Dashboard · Monitoring · RoomDetail · Devices · Alerts · Settings
└── ui.jsx         # 공용 컴포넌트 (카드, 배지, 스위치 …)
```

**스택**: React 19 · Vite · react-router · recharts · lucide-react · Wanted Sans

> [!WARNING]
> 시연용 데모 계정(`admin` / `1234`, 로고 더블클릭으로 자동 입력)과 인증 코드(`123456`)가 들어 있어요.
> 실제 서버에 연결하기 전에 `src/auth/authApi.js`에서 지워야 해요.
