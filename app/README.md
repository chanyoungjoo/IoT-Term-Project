# 📱 AirClass 앱

담임 선생님이 **내 교실 공기를 확인하고, 창문과 공기청정기를 바로 제어**하는 앱이에요.
Expo(React Native)로 만들었고, 같은 코드로 휴대폰 브라우저용 웹 빌드도 만들어요.

> 지금은 `shared/dummyData.js`의 더미 데이터로 동작해요. 데이터는 모두 `src/api.js`를 거치므로, 백엔드를 붙일 때 이 파일만 바꾸면 돼요.

---

## 화면 (하단 탭 5개)

### 🏠 홈
- 내 교실의 PM2.5 · CO₂ · 온습도와 **실내·외 PM2.5 비교**
- 상태에 따라 화면 색과 창문 그림이 바뀌어요.

  | 🔵 정상 | 🟠 CO₂ 높음 | 🌑 실외 나쁨 |
  |---|---|---|
  | 창문 닫힘 | 창문이 열리는 애니메이션 | 창문 닫힘 + 먼지 차단 |
  | 추천 없음 | **창문 열기 추천** + [창문 열기] | **창문 닫기 추천** + [창문 닫기] |

- 창문 카드에서 **버튼 한 번으로 실행**하면 "방금 창문을 열었어요"로 바뀌어요.
- 아래 **시연용 상태 전환** 버튼으로 세 상태를 바로 바꿔 볼 수 있어요.

### 🎛️ 제어
- 창문 [열기] [닫기] + 추천 표시
- 공기청정기 전원 · 풍량(약 · 중 · 강 · 터보)
- 토글: 공기청정기 자동 제어, 창문 추천 알림

### 🤖 AirChat
교실 공기 도우미예요. **말로 부탁하면 예약과 자동화 규칙을 만들어 줘요.**

| 이렇게 말하면 | AirChat이 하는 일 |
|---|---|
| "1분 뒤에 청정기 켜줘", "3시 반에 창문 닫아줘" | ⏰ **예약** 카드 제안 (오늘 한 번 실행) |
| "시험 시간엔 청정기 꺼줘", "CO₂ 높고 바깥 괜찮으면 창문 열어줘" | ⚡ **자동화 규칙** 카드 제안 (조건마다 반복) |
| "청정기 왜 켜졌어?" | 📋 제어 기록을 찾아 근거와 함께 설명 |
| "지금 켜줘" | 제어 탭에서 바로 하라고 안내 |

- **AirChat은 장치를 직접 움직이지 않아요.** 카드에서 선생님이 [예약하기] / [규칙 저장]을 눌러야 등록돼요.
- 청정기를 끄는 규칙에는 "PM2.5 35 이상이면 다시 켜기" 같은 **안전 예외**가 꼭 붙어요.
- 등록된 예약·규칙은 오른쪽 위 **자동화** 버튼에서 개수와 목록을 볼 수 있어요.
- 연결 방식
  - **서버 모드**: `/api/chat`(`../server`) → Claude Haiku. 화면에 "Claude 연결됨" 표시
  - **기본 응답 모드**: 서버에 닿지 않으면 앱 안의 규칙 기반 엔진(`src/airchat.js`)으로 자동 전환돼요. 두 모드의 답 모양이 같아서 화면은 똑같이 동작해요.

### 📈 기록
- 오늘의 공기 기록: CO₂ · PM2.5 추세
- 환기 · 공기청정 기록(창문 열림, 공기청정기 가동, 환기 알림)

### ⚙️ 설정
- 내 교실 관리(기본 교실 선택), 알림 기준값(행정실이 정한 값 표시), 로그아웃

### 🔐 시작 화면
로그인 · 회원가입(담당 교실 선택) · 아이디/비밀번호 찾기를 거쳐 홈으로 들어가요.

## 실행

```bash
npm install
npx expo start       # Expo Go로 QR 스캔 (처음엔 npx expo login)
npm run ios          # Mac + Xcode면 시뮬레이터로
npm run build:web    # 웹 빌드 → dist/ (라즈베리파이 nginx가 /app/ 으로 서빙)
```

맥에서 개발하면서 라즈베리파이의 AirChat 서버를 쓰려면 `app/.env`에 넣어요. (없으면 기본 응답 모드)

```bash
EXPO_PUBLIC_API_URL=https://<라파이름>.<tailnet>.ts.net
```

## 구조

```
src/
├── app/                # expo-router 탭 화면: index(홈) · control · airchat · forecast(기록) · settings
├── auth/               # 로그인 · 회원가입 · 계정 찾기 (AuthFlow, authApi는 데모용)
├── api.js              # 데이터 접근 창구 (지금: shared/ 더미 → 나중: 백엔드 API)
├── store.js            # 앱 전체 상태 (시연 상태, 장치 조작 결과)
├── airchat.js          # AirChat: 서버 호출(remoteReply) + 기본 응답 엔진(reply)
├── useAirChat.js       # AirChat 대화 · 예약 · 규칙 상태 관리
├── AirChatParts.jsx    # 말풍선, 예약·규칙 카드, 추천 문장 칩
├── WindowCard.jsx      # 창문 카드 (상태 + 추천 + 원탭 실행)
├── WindowArt.jsx       # 상태별로 움직이는 창문 그림
└── Splash.jsx · motion.jsx   # 시작 애니메이션 · 공용 모션
```

**스택**: Expo SDK 58 · expo-router · react-native-svg · lucide-react-native · Wanted Sans
(애니메이션은 React Native `Animated`만 사용, iOS '동작 줄이기' 설정을 따라요)

> [!WARNING]
> 시연용 데모 계정(`admin` / `1234`, 로그인 화면 로고를 길게 누르면 자동 입력)과 인증 코드(`123456`)가 들어 있어요.
> 실제 서버에 연결하기 전에 `src/auth/authApi.js`에서 지워야 해요.
